# 연휴각 (가칭) 상세 기획서

> 기능 목록이 아니라 사용자가 겪는 순간을 기준으로 정리한 문서다.
> 모든 결정은 "처음 쓰는 사람이 설명 없이 바로 쓸 수 있는가"로 판단한다.

## 1. 누가 어떤 순간에 여는가

| 사용자 | 여는 순간 | 원하는 것 | 설계 대응 |
|---|---|---|---|
| 입사 1년 미만 신입 | 첫 여름휴가 계획 | 지금 연차가 몇 개인지부터 모름 | 남은 개수 모르면 입사일만으로 계산 |
| 연말 소진형 | 11~12월 연차 소멸 전 | 남은 몇 개를 빨리 어디에 쓸지 | 기간 필터 "올해 남은 기간"을 첫 화면 기본값으로 |
| 연초 계획형 | 1월 새해 계획 | 1년치 연휴를 한 번에 배치 | 연간 자동 배치 버튼 |
| 가족 일정형 | 명절·방학 전 | 특정 기간 주변만 보고 싶음 | 월·시즌 필터 |
| 공무원·교사 | 언제든 | 규정이 달라 자동 계산이 틀림 | 남은 개수 직접 입력이 기본 경로라 문제 없음 |
| 교대 근무자 | 언제든 | 주말 개념이 다름 | v1 미지원을 설정에 명시. 직접 지정은 가능 |

공통점: 사람들은 연차 규칙을 알고 싶은 게 아니라 **며칠 쉴 수 있는지**만 알고 싶다. 규칙은 뒤에 숨기고 결과를 앞에 둔다.

## 2. 화면 구성

```
하단 탭 3개
[ 달력 ]  [ 추천 ]  [ 내 연차 ]
상단: 연도 선택(2027 ▾) · 오늘 버튼 · 설정(톱니)
```

- **달력**: 메인. 공휴일·주말·내 연차가 한눈에. 그어서 지정.
- **추천**: 남은 연차로 만들 수 있는 연휴 후보 리스트. 탭하면 달력에 미리보기.
- **내 연차**: 남은 개수·사용 기록·소멸 예정. 숫자 수정은 여기서 한 번에.
- 설정은 탭이 아니라 상단 아이콘. 자주 안 쓰는 걸 탭에 올리지 않는다.

### 첫 실행 흐름 (30초 목표)
1. **질문 하나**: "올해 남은 연차가 몇 개예요?" 큰 스테퍼(0.5 단위 · 기본 15). 아래 작은 링크 "잘 모르겠어요 → 입사일로 계산하기"
2. **바로 추천 화면**으로 이동. 가장 효율 좋은 연휴 3개가 카드로 보인다.
3. 카드 탭 → 달력에 반투명 미리보기 → "달력에 담기" 버튼
4. 달력 첫 진입 시 코치마크 1회: "꾹 누른 채 밀면 여러 날을 한 번에 지정해요"
- 근무 요일·회사 휴무일 설정은 온보딩에서 묻지 않는다. 기본값(월~금)으로 시작하고 설정에서 바꾼다.

## 3. 연도 범위와 공휴일 데이터

### 범위
- 탐색 가능 연도: **2020 ~ 2035**. 연도 선택기에서 자유롭게 이동.
- 기본 연도: 오늘 기준 올해. 단 11월 이후 첫 실행이면 추천 화면에 "내년 보기" 칩을 강조.

### 데이터 3단계
| 단계 | 내용 | 표시 |
|---|---|---|
| 확정 | 한국천문연구원 특일정보 기준 발표된 공휴일 | 일반 표시 |
| 예상 | 미발표 연도. 고정 공휴일 + 음력 공휴일 + 대체공휴일 규칙으로 계산 | 연도 옆 `예상` 배지 + 상세에 설명 |
| 원격 덮어쓰기 | 임시공휴일·선거일 등 늦게 발표되는 날 | 새로 추가된 날에 작은 점 + 알림(동의 시) |

- 앱 번들: `assets/holidays/kr_holidays.json` (연도별 `confirmed: true/false`)
- 음력 변환: 앱에서 계산하지 않는다. `tools/lunar_table.py`로 천문연구원 음양력 데이터를 받아 2020~2035 변환표를 미리 만들어 번들한다.
- 대체공휴일 규칙은 `:core:engine`의 `SubstituteHolidayRule`로 구현하고 연도별 적용 범위(설·추석·어린이날·국경일·부처님오신날·성탄절 확대 시점)를 데이터로 관리한다.
- 원격 JSON: GitHub Pages에 `holidays_override.json` 호스팅. 스키마 검증 실패·네트워크 실패 시 번들 데이터 그대로 사용. 주 1회 WorkManager로 확인.
- 선거일은 계산하지 않고 원격 데이터로만 추가한다.
- 5월 1일 노동절 · 7월 17일 제헌절: 2026년부터 공휴일(KASI 특일정보 기준). 회사 휴무일 프리셋이 아니라 공휴일로 처리한다. 고정 공휴일 규칙에 적용 시작 연도(`sinceYear`)로 관리하고, 주말과 겹치면 대체공휴일 대상이다(제헌절은 국경일 묶음, 노동절은 별도 묶음).
- 공휴일 이름은 KASI 표기 원문을 저장·비교하고 화면에는 표시 이름을 쓴다(`HolidayKey` → `strings.xml`). 예: `기독탄신일` → `성탄절`, `대체공휴일(기독탄신일)` → `대체공휴일(성탄절)`. 키가 없는 선거일·임시공휴일은 원문 그대로.

## 4. 연차 계산 규칙

- 근로기준법 기준 (입사일 기준)
  - 1년 미만: 1개월 개근 시 1일. 최대 11일
  - 1년 이상 · 80% 이상 출근: 15일
  - 3년 이상: 최초 1년 초과 매 2년마다 1일 가산. 최대 25일
- 회계연도 기준: 입사 다음 해 1월 1일에 재직 비율만큼 비례 부여 + 월 개근분. 설정에서 선택.
- 5인 미만 사업장 토글: 켜면 자동 계산 대신 "회사 규정에 따라 직접 입력해 주세요" 안내.
- 반차 0.5 · 반반차 0.25(설정에서 켜야 보임. 기본 꺼짐)
- 화면에는 항상 `참고용 계산이에요. 회사 규정이 우선이에요` 한 줄.
- **사용자가 직접 입력한 남은 개수가 항상 계산값보다 우선**한다.

## 5. 추천 엔진

### 정의
- 근무일 = 근무 요일 ∧ 공휴일 아님 ∧ 회사 휴무일 아님 ∧ 이미 연차 아님
- 연휴 블록 = 연속된 비근무일 구간. 연차로 근무일을 메우면 블록이 합쳐진다.
- 비용 = 블록 안에서 연차로 메운 근무일 수
- 효율 = 총 휴일 수 ÷ 비용

### 출력
1. **단일 후보 리스트**: 비용 1~남은 개수 범위의 모든 극대 블록. 정렬 기본 = 효율 높은 순 → 같으면 길이 긴 순. 정렬 바꾸기: 긴 순 · 날짜 순.
   - 총 3일 미만 블록은 후보에서 뺀다(달력 연휴 띠 기준과 같다).
   - 달력에 이미 지정한 연차 1일은 쉬는 날로 보고 이어 붙인다(반차는 출근일). 남은 개수는 총량에서 지정분을 뺀 값으로 계산한다.
   - 카드 일수와 달력 띠 일수는 같은 엔진 함수(`VacationSpan`)로 센다.
2. **연간 자동 배치**: 겹치지 않게 효율 순으로 탐욕 배치. 결과는 "제안"으로만 보여주고 사용자가 담아야 저장된다.
3. 필터 칩: 올해 남은 기간 · 계절 · 월 · 최소 길이(3일+ / 5일+ / 9일+)
   - 기본은 올해 남은 기간. 오늘 이전 날짜가 들어간 연휴(주말·기존 연차로 앞이 이어진 경우 포함)는 빼고 보여준다.

### 엣지 처리
- 연도를 넘는 블록(12월 말~1월 초): 각 연도 연차에서 따로 차감하고 카드에 두 연도 표시.
- 남은 연차 0: 빈 화면 대신 "연차 없이 쉬는 날" 리스트(공휴일+주말로 이미 3일 이상인 구간) 보여주기.
- 반차는 추천에 쓰지 않는다. 직접 지정에서만.

### 카드 문구 예시
```
연차 2일 → 5일 휴가
5월 2일(금) ~ 5월 6일(화)
효율 2.5배 · 어린이날 연휴
```

| 길게 누른 채 드래그 | 범위 선택. 근무일만 차감 | 날짜 넘어갈 때마다 미세 햅틱 + 말풍선 `연차 3일 → 9일 휴가` |

- 드래그와 스와이프 충돌 방지: 드래그 선택은 **200ms 길게 누름 후**에만 시작한다. 시작 순간 햅틱으로 모드 전환을 알린다.
- 남은 연차 초과: 막지 않는다. 말풍선이 경고색 + `2일 초과`로 바뀐다. 손을 떼면 그대로 지정하고 내 연차 탭에 마이너스로 표시.
- 모든 지정·해제·범위 선택 후 Undo 스낵바 5초.
- 공휴일 위를 탭하면 공휴일 이름 툴팁만 보여준다(연차 지정 안 됨).
- TalkBack: 날짜마다 "5월 2일 금요일 근무일 · 두 번 탭하면 연차 지정" 형태. 범위 선택은 길게 누르기 시트의 "여기부터 선택" · "여기까지 선택" 커스텀 액션으로 대체.
- 셀 최소 터치 영역 48dp. 작은 화면에서 셀이 작아지면 날짜 숫자 크기만 줄이고 터치 영역은 유지.

## 7. 테마 시스템

### 결론: 테마 선택 + 테마 안의 월별 변화
월별 배경 변화와 테마 선택은 둘 중 하나가 아니라 **층이 다른 기능**이다. 테마를 고르면 그 테마가 월이 바뀔 때 어떻게 변할지까지 정의한다. 계절 테마는 월별 변화가 크고 기본 노트는 거의 변하지 않는다.

### 테마 구조
```kotlin
data class YhThemeSpec(
    val id: ThemeId,
    val light: YhColors, val dark: YhColors,
    val numeralFont: FontFamily,      // 숫자·제목만 테마 폰트
    val bodyFont: FontFamily,         // 본문은 항상 Pretendard
    val cellStyle: CellStyle,         // 모서리·채움 방식
    val monthBackdrop: MonthBackdrop, // 월별 배경 그리기 (Canvas)
    val transition: MonthTransition,  // 월 넘김 효과
    val soundPack: SoundPack,
)
```
- 본문 폰트는 모든 테마에서 Pretendard로 고정한다. 테마는 숫자·제목·배경·소리만 바꾼다. 가독성은 테마보다 우선.
- 배경은 이미지가 아니라 Canvas로 그린다. 앱 용량을 늘리지 않고 다크 모드·화면 크기에 자동 대응.
- 다크 모드(시스템 따르기 · 라이트 · 다크)는 테마와 별개 설정. 모든 테마가 두 모드를 가진다.

### 5개 테마
| 테마 | 성격 | 핵심 토큰 (라이트) | 월별 변화 | 월 넘김 | 소리 |
|---|---|---|---|---|---|
| 기본 노트 (기본값) | 가장 읽기 쉬움 | bg #FFFFFF · ink #1E2430 · holiday #D7263D · sat #2E5AAC · accent #3A86FF | 없음 | 슬라이드 | 부드러운 틱 |
| 계절 | 달마다 공기가 바뀜 | 월별 accent (1월 #7FA7D9 눈 · 4월 #F2A7B8 꽃 · 7월 #2BB3C0 물 · 10월 #D9822B 낙엽 · 12월 #3D5A80 밤) | 크다: 1월 눈 · 3~4월 꽃잎 · 7~8월 물결 · 10~11월 낙엽 · 12월 별. 입자 20개 이하 | 배경 크로스페이드 + 슬라이드 | 계절 소품 소리(눈 밟기 · 바람 · 물방울) |
| 아날로그 | 모눈 다이어리 + 형광펜 | bg #F6F4EC · 모눈선 #B9CCE4 · ink #23395B · holiday #B5332E(도장 느낌) · 연차 = 형광펜 #F5E663 | 표지 색만 계절별 미세 변화 | 종이 넘김(그림자 + 슬라이드) | 종이 넘김 · 형광펜 긋기 |
| Lo-fi | 밤 방 안 스탠드 불빛 | bg #2F3A4A · ink #EADFC8 · accent #F2A65A · holiday #E86A6A · sat #8FB8DE (라이트 변형 bg #DCD6E8) | 창밖 풍경만 계절별로 바뀜 | 그레인 낀 페이드 | 카세트 버튼 · 바이닐 잡음 |
| 야구 | 구장 전광판 | bg #0E3B2E · 숫자 #F7F3E3 · accent #F2C14E(전구) · holiday #FF6B5B · sat #7FC8F8 | 비시즌(11~2월)은 조명 꺼진 전광판, 시즌은 켜진 전광판 | 숫자 플립 | 공 받는 소리 · 짧은 함성 |

- **야구 테마 주의**: 구단 로고·구단명·마스코트·실제 선수명 사용 금지. 응원 색은 `빨강 · 파랑 · 남색 · 주황 · 초록 · 검정` 일반 팔레트 6개 중 선택하게 하고 구단을 연상시키는 이름을 붙이지 않는다. 연차 지정 시 표시는 `SAFE` 대신 한국어 `세이프`.
- 폰트는 전부 OFL 라이선스: Pretendard(본문) · 나눔손글씨 계열(아날로그 숫자) · Galmuri(Lo-fi 제목) · 전광판 느낌 도트 폰트(야구 숫자). 각 폰트 라이선스 파일을 `licenses/`에 둔다.

### 테마 선택 화면
- 설정 → 테마. 카드마다 **이번 달 실제 내 달력**을 축소해 미리보기로 보여준다(샘플 이미지 아님).
- 카드 탭 = 즉시 적용 + 스낵바 `Lo-fi로 바꿨어요 · 되돌리기`
- 카드 안 스피커 아이콘으로 소리 미리 듣기.
- 계절 테마는 미리보기에서 좌우로 넘기면 다른 달 분위기를 볼 수 있다.

### 효과음
- 생성 방식: `tools/sfx/generate.py`(numpy)로 합성해 OGG로 출력. 외부 음원 사용 안 함 → 라이선스 문제 없음 · 결정적 재현 가능.
- 팩 구성: `page` · `mark` · `unmark` · `success` 4종 × 테마 5개. 각 300ms 이하.
- 재생: SoundPool · `USAGE_ASSISTANCE_SONIFICATION`.
- 설정: 효과음 `시스템 따르기(기본) · 켜기 · 끄기` / 햅틱 `켜기(기본) · 끄기`
- 시스템 따르기 = 벨소리 모드일 때만 재생. 진동·무음 모드면 재생 안 함.
- 애니메이션 줄이기(시스템 설정)가 켜져 있으면 월 넘김은 100ms 크로스페이드, 배경 입자는 정지 상태로 그린다.

## 8. 공유 카드 · 위젯 · 알림

### 공유 카드
- 크기 선택: 피드(4:5) · 스토리(9:16). 현재 테마가 그대로 적용된다.
- 내용: 연도 · 연휴 블록 목록 · 총 휴일 수 · 쓴 연차 수. 입사일 등 개인 정보는 넣지 않는다.
- 하단 작은 앱 이름 + QR(설정에서 끌 수 있음).
- 기기 안에서 생성 → 안드로이드 공유 시트.

### 위젯 (Glance)
- 2×1: `다음 연휴까지 D-12` + 연휴 이름
- 4×2: 이번 달 미니 달력 + 남은 연차
- 테마 색 따라감. 탭하면 해당 날짜로 앱 열림.

### 알림 (전부 선택형)
- 권한은 첫 실행에 묻지 않는다. 사용자가 처음 연휴를 달력에 담은 직후 물어본다: `연휴 3주 전에 알려드릴까요?`
- 종류: 연휴 D-21(예약 챙기기) · 연차 소멸 D-30(입사일 입력 시) · 새 공휴일 추가(원격 데이터 변경 시)

## 9. 문구 규칙

- 해요체. 한 문장은 한 가지 일만.
- 버튼은 무엇이 일어나는지 말한다: `달력에 담기` → 완료 스낵바도 `달력에 담았어요`. 같은 행동은 끝까지 같은 단어.
- 전문 용어 대신 결과: `발생 연차` 대신 `올해 생기는 연차`
- 오류는 무엇이 문제고 어떻게 하면 되는지: `공휴일 정보를 새로 받지 못했어요. 저장된 정보로 보여드릴게요`
- 빈 화면은 다음 행동을 제안: `아직 담은 연휴가 없어요. 추천에서 골라볼까요?`

## 10. 사용성 체크리스트 (단계마다 자체 검토)

- [ ] 처음 쓰는 사람이 설명 없이 첫 추천까지 30초 안에 가는가
- [ ] 화면마다 가장 중요한 행동이 하나로 분명한가
- [ ] 모든 변경에 되돌리기가 있는가
- [ ] 사용자가 직접 계산해야 하는 숫자가 남아 있지 않은가 (주말 차감 등)
- [ ] 한 손 엄지로 주요 버튼에 닿는가 (하단 배치)
- [ ] 글자 크기 200%에서 잘리거나 겹치지 않는가
- [ ] 다크 모드 × 5테마 모두 대비 4.5:1 이상인가
- [ ] 색을 못 구분해도 공휴일·연차·반차를 구분할 수 있는가
- [ ] TalkBack만으로 연차 지정과 범위 선택이 가능한가
- [ ] 무음 모드에서 소리가 나지 않는가
- [ ] 광고가 입력 흐름이나 달력 편집 화면에 없는가
- [ ] 네트워크 없이 모든 핵심 기능이 동작하는가
- [ ] 오류·빈 화면에 다음 행동이 안내되는가
- [ ] 예상 데이터가 확정처럼 보이지 않는가

## 11. 광고 · 수익

- **배너**: 추천 리스트 하단 · 내 연차 하단에만. 달력 화면에는 넣지 않는다(드래그 중 오클릭 방지).
- **보상형**: 추천 상위 5개는 무료. `전체 후보 보기`를 누르면 보상형 광고 후 24시간 전체 공개. 광고 로드 실패 시에는 그냥 열어준다(사용자 탓 아님).
- **전면 광고**: v1에서는 넣지 않는다. 지표 확인 후 결정.
- **광고 제거 1회 구매**: v1.1.
- 개발 중에는 반드시 테스트 광고 ID. 릴리스 빌드에서 테스트 ID가 남아 있으면 빌드 실패하도록 검사.

## 13. 자동 QA 설계

### 테스트 피라미드
| 층 | 도구 | 무엇을 | 언제 |
|---|---|---|---|
| 엔진 단위 | JUnit5 + Kotest | 공휴일 규칙 · 연차 계산 · 추천 | 커밋마다 |
| 엔진 속성 | kotest-property | 아래 불변식을 무작위 입력 1,000회 | 커밋마다 |
| 골든 데이터 | JUnit + JSON 스냅샷 | 번들 공휴일 = 천문연구원 데이터 | 커밋마다 + 야간 동기화 |
| 테마 토큰 | JUnit | 모든 테마 × 모드의 글자/배경 대비 ≥ 4.5:1 | 커밋마다 |
| 효과음 | pytest | 길이 ≤ 300ms · 피크 ≤ -1dBFS · 팩 누락 없음 | 커밋마다 |
| UI 컴포넌트 | Compose UI Test (Robolectric) | 탭·길게누르기·드래그·Undo | PR |
| 스크린샷 회귀 | Roborazzi | 화면 3종 × 테마 5 × 라이트/다크 × 글자 100/200% + 계절 테마 12개월 | PR |
| 접근성 | Compose semantics 검사 헬퍼 | 터치 영역 48dp · contentDescription · 역할 | PR |
| E2E | Maestro (에뮬레이터) | 첫 실행 → 추천 → 담기 → 테마 변경 → 공유 | 야간 |
| 안정성 | adb monkey 5,000 이벤트 | 크래시·ANR 0 | 야간 |
| 릴리스 | `tools/release_check.sh` | 테스트 광고 ID 잔존 · versionCode 증가 · 방침 URL 응답 | 릴리스 전 |

### 엔진 불변식 (속성 테스트)
1. 추천 블록의 비용 ≤ 남은 연차
2. 연차는 비근무일에 절대 배치되지 않는다
3. 총 휴일 수 ≥ 비용
4. 추천 블록은 극대다(양 끝 바로 바깥이 근무일)
5. 연간 자동 배치 결과 블록끼리 겹치지 않는다
6. 연도 경계 블록의 비용은 두 연도 합과 같다
7. 대체공휴일은 원래 공휴일과 같은 날이 아니다
8. 연차 계산값은 0 이상 25 이하

### CI (GitHub Actions)
- `pr.yml`: ktlint · detekt · lint → 단위/속성 테스트 → 스크린샷 검증 → assembleDebug
- `nightly.yml`: `tools/holiday_sync.py`로 천문연구원 데이터 받아 번들과 비교 → 차이 있으면 이슈 자동 생성 / 에뮬레이터에서 Maestro + monkey
- API 키는 GitHub Secrets에만 둔다.

### QA 기록
- `docs/QA_LOG.md`: 단계별 통과 명령 · 추가 테스트 수 · 남은 이슈
- `docs/BUGS.md`: 재현 스텝 · 기대 결과 · 실제 결과 · 원인 · 수정 커밋
